# Neural Networks

A collection of Jupyter notebooks covering data analysis and neural network experiments.

## Notebooks

| Notebook | Description |
|----------|-------------|
| `Data Analysis.ipynb` | General data analysis exercises |
| `Mall Customer Segmentation Dataset.ipynb` | Customer segmentation using clustering |
| `Neural Networks Fashion-MNIST.ipynb` | Image classification on Fashion-MNIST |
| `Neural Networks From scratch using MNIST Classification.ipynb` | Building a neural network from scratch on MNIST |

## Requirements

- Python 3.x
- Jupyter Notebook or JupyterLab
- Common ML libraries (NumPy, Pandas, Matplotlib, etc.)

## Getting Started

```bash
jupyter notebook
```

Open any notebook from the file list and run the cells in order.
